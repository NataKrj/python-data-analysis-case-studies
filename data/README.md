# Data

This folder contains compact, reproducible data snapshots used by the portfolio case studies.

- `volkswagen_listings_snapshot.csv` — 30 historical Volkswagen listings extracted from the original public web-data analysis.
- `bike_sharing_sample.csv` — stratified sample of the bike-sharing dataset, preserving coverage across seasons and hours of the day.
- `latvia_temperature_location_sample.csv` — deterministic sample of 10 coordinate locations from the public Latvia temperature dataset.
- `latvia_temperature_daily_summary.csv` — daily min/mean/max temperature summary calculated from the full public Latvia temperature dataset (599,640 observations).

The repository contains only public or sample data and no client, employer or confidential information.
